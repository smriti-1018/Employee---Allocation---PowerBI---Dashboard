Employee Allocation & Project Performance Dashboard

Project Overview
This project is an interactive Power BI dashboard designed to analyze employee allocation and project performance.

Tools & Technologies
- Power BI
- Data Modeling
- DAX
- Data Visualization

Key Features
- Total Planned Hours
- Total Actual Hours
- Variance Hours
- Employee Utilization
- Project-wise Performance
- Employee-wise Planned vs Actual Hours
